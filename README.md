## 📖 Sobre

Esta é uma **Pokedex interativa**, desenvolvida para exibir informações de Pokémons de forma dinâmica e intuitiva.

O projeto foi criado com foco em aprendizado prático de desenvolvimento front-end, consumindo dados e manipulando a interface com JavaScript.
